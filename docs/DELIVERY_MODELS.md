# BlackSentinel Pulse - Delivery Models

## Overview

BlackSentinel Pulse can be delivered to organizations through multiple models,
each designed for different needs, budgets, and technical capabilities.

---

## 1. SaaS (Software as a Service)

**Best for:** Small to medium organizations, quick adoption

### How it works
- Hosted by BlackSentinel on cloud infrastructure
- Organizations access via browser
- Multi-tenant architecture
- Managed updates and maintenance

### Pricing Model
| Tier | Monthly | Annual | Includes |
|------|---------|--------|----------|
| Starter | $499/mo | $4,990/yr | 1,000 assets, 5 users |
| Professional | $1,999/mo | $19,990/yr | 10,000 assets, 25 users |
| Enterprise | $4,999/mo | $49,990/yr | 100,000 assets, unlimited users |

### Deliverables
- Account provisioning via API or portal
- Custom branding available (white-label)
- SLA: 99.9% uptime
- Support: Email + chat + phone (Enterprise)

---

## 2. Managed Service

**Best for:** Organizations wanting ASM without in-house expertise

### How it works
- BlackSentinel hosts and manages the platform
- Dedicated instance per customer
- BlackSentinel team operates and monitors
- Customer accesses via secure portal

### Pricing Model
- Setup fee: $5,000 - $15,000
- Monthly: $2,999 - $9,999 (based on asset count)
- Includes: 24/7 monitoring, monthly reports, remediation guidance

### Deliverables
- Dedicated infrastructure
- Custom onboarding (1-2 weeks)
- Monthly security reports
- Quarterly business reviews
- Dedicated CSM (Enterprise)

---

## 3. On-Premise Deployment

**Best for:** Regulated industries, air-gapped networks, data sovereignty

### How it works
- Deployed on customer's infrastructure
- Full data control
- Custom integration with existing tools
- Customer manages updates

### Pricing Model
- License: $25,000 - $100,000/year
- Implementation: $15,000 - $50,000
- Support: $5,000 - $20,000/year

### Deliverables
- Docker images + Helm charts
- Installation documentation
- Implementation support (40-120 hours)
- Training sessions (2-5 days)
- 12-month support contract

### Requirements
- Kubernetes cluster or Docker host
- PostgreSQL 16+
- Redis 7+
- Neo4j 5+
- Network access to cloud APIs (for discovery)

---

## 4. Hybrid Deployment

**Best for:** Large enterprises, multi-region

### How it works
- Control plane hosted by BlackSentinel
- Data plane deployed in customer's cloud
- Data never leaves customer's infrastructure
- Centralized management portal

### Pricing Model
- Platform fee: $5,000 - $20,000/month
- Per-node licensing: $500 - $2,000/month
- Implementation: $25,000 - $100,000

### Deliverables
- Hybrid architecture design
- Data plane deployment package
- Control plane access
- Custom integrations
- Dedicated support team

---

## 5. White Label / Reseller

### Deliverables

## Choosing the Right Model

### Ask these questions:

1. **Data sensitivity?** → On-Prem or Hybrid
2. **Budget constraints?** → SaaS (lower upfront)
3. **Compliance requirements?** → On-Prem or Managed
4. **Internal expertise?** → Managed or SaaS
5. **Growth plans?** → SaaS or Hybrid
6. **Brand requirements?** → White Label
7. **Unique needs?** → Custom Development
